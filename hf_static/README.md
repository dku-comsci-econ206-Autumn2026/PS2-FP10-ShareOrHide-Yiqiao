# Share or Hide?

This Static Hugging Face Space is an exploratory classroom decision exercise for
COMSCI/ECON 206. It asks how competing drone operators balance coordination
benefits against commercial-confidentiality costs when choosing voluntary
flight-intent disclosure.

The browser does not reimplement or rerun the Bayesian solver. The finite model
outcomes in `data/validated_model_data.json` are generated by
`scripts/export_static_model_data.py` in the source project using the validated
Python model at commit `791e12224576e5963fd5672f8f90acdcea5556a0`.

## Privacy and evidence boundary

No account is required inside the app. The project collects no name, email,
student ID, or other identifying field. Choices and optional reflections remain
in browser memory and disappear on refresh; they are not sent to a server,
database, analytics service, external API, or LLM.

**Evidence boundary:** This Space is an exploratory classroom decision exercise.
Participant choices are not a representative sample of drone operators, firms,
or the public. They do not establish how real operators would behave and do not
validate the model's external accuracy.

Numerical parameters are stylized normalized benchmarks rather than empirically
calibrated estimates.

## Scope and limitations

The model has two operators, binary independent private types, three voluntary
disclosure levels, three public congestion states, and pure-strategy Bayesian
benchmarks. Mandatory safety information is always available. The CCAR mechanism
changes only access to enhanced non-safety coordination information. The
priority-slot auction is a bounded downstream application for eligible
commercial flights; emergency and public-safety flights remain outside it.
